# Design System: Heritage Modernity

## Core Vision
This design system has transitioned into a high-contrast, dark-mode experience that blends a luxurious, traditional palette with contemporary, ultra-soft geometry. It moves away from the previous editorial serif style toward a cleaner, tech-forward sans-serif aesthetic while maintaining its prestigious color foundation.

## Visual Principles

### Color Palette
*   **Primary (Gold - #D4AF37):** Used as the primary interactive anchor and brand signature, cutting through the dark interface with high visibility.
*   **Secondary (Deep Forest - #2D5A27):** Supports secondary actions and specialized UI components, providing a grounded, organic contrast.
*   **Tertiary (Deep Madder - #A33B33):** Reserved for accents, notifications, or decorative highlights.
*   **Neutral (#F5F0E1):** While defined as a light cream, in this dark-mode context, it serves as the base for high-contrast text and subtle surface overlays against the dark background.

### Typography
The system utilizes a triple-sans-serif stack to maximize readability and modern appeal:
*   **Headlines (Manrope):** A geometric sans-serif that provides a clean, authoritative structure to page hierarchies.
*   **Body (Public Sans):** A strong, neutral typeface designed for clarity and reading resilience across all screen sizes.
*   **Labels (Spline Sans):** Optimized for UI precision, ensuring that functional text and micro-copy remain distinct.

### Shape and Geometry
The interface adopts a **maximum roundedness (Level 3)**. Buttons, cards, and input fields utilize pill-shaped profiles and deeply radiused corners, creating a friendly, fluid, and modern tactile feel that contrasts with the traditional color palette.

### Layout and Space
The system employs **Normal spacing (Level 2)**. This creates a balanced density that is neither too cramped nor overly airy, suitable for functional applications that require efficient information display without sacrificing breathing room.

## Component Specifications
*   **Interactive Elements:** Full pill-shaped radii (roundedness 3) applied to all buttons and chips.
*   **Surfaces:** Dark mode backgrounds with gold primary accents and subtle cream-toned typography.
*   **Hierarchy:** Established through the bold weight of Manrope headlines against the functional clarity of Public Sans body copy.
